```bash
npx prisma migrate deploy        # applies the seven migrations above
npx prisma generate
npm run build
npm start                        # and, separately:
npm run worker
```

On the worker's first start after this change it **removes stale job
schedulers** (T38): in the current Redis that is the 7 duplicate
`name:workspace` schedulers that ran every recurring job twice for the LST
workspace. Historic failed-job records are left to age out (7-day retention).

Rolling back code without rolling back the schema is safe: the old code never
reads the new tables or columns.

new code before a LinkedIn search is started: an old worker would run the old
single-page adapter and ignore the new options. Nothing about it needs a paid
